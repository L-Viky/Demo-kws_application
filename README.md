To run the demo, type the following command in two different terminals:

    python3 -m http.server 8000
    npx localtunnel --port 8000

Then you need to go to the link provided by the second command, adding the name of the HTML file:

    https://<your-localtunnel-subdomain>.loca.lt/<your-html-file>.html 
    (in this case, it would be https://<your-localtunnel-subdomain>.loca.lt/kws_smart_home_v4.html)

Once you’ve done that, when the web page loads, you’ll be able to install the app and it will work even without an internet connection.
